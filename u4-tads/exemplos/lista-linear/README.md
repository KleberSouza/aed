# 📚 Exemplo: TAD - Lista Linear

## 📝 Descrição

A **Lista Linear** é uma estrutura de dados que armazena elementos de forma sequencial, com inserções e remoções controladas. É ideal para cenários onde a ordem de inserção importa e o acesso por posição é frequente.

Ela pode ser implementada de duas formas principais:
- **Estática (vetor)**: tamanho fixo, alocado previamente.
- **Dinâmica (ponteiros)**: tamanho flexível, alocado conforme a necessidade.

Nesta seção, vamos focar na **implementação estática (com vetor)**.

---

## 🧠 Conceitos Envolvidos

- Armazenamento sequencial de dados
- Controle de tamanho e posição de inserção
- Operações básicas: inserir, remover, buscar, listar
- Manipulação de índices

---

## 💡 Aplicações

- Manutenção de listas ordenadas ou não ordenadas
- Simulação de estruturas de dados complexas
- Implementações de algoritmos onde ordem de elementos é importante

---

## ⚙️ Operações Comuns

| Operação           | Descrição                                      |
|--------------------|-----------------------------------------------|
| Inserção no final  | Adiciona um elemento ao final da lista        |
| Inserção em posição| Insere elemento em posição específica         |
| Remoção            | Remove elemento por valor ou posição          |
| Busca              | Retorna índice ou valor se existir na lista   |
| Listar             | Percorre todos os elementos da lista          |
